# Sabor Express
Projeto de estudo feito nas aulas de Python da Alura.
Aplicação de terminal para cadastrar, listar e ativar restaurantes.

## Como rodar

    python sabor_express.py

Observação: usa `os.system('cls')`, então funciona no Windows.

## Funcionalidades

- Cadastrar restaurante
- Listar restaurantes
- Ativar restaurante (em desenvolvimento)
