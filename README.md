# Sabor Express
Projeto de estudo feito nas aulas de Python da Alura.
Aplicação de terminal para cadastrar, listar e alternar estados de restaurantes.

## Como rodar

Com o Python 3 instalado, execute no terminal:

```bash
python app.py
```

## Funcionalidades

- Cadastrar restaurante
- Listar restaurantes
- Alternar estados dos restaurantes

## Sobre o projeto

### O que aprendi

- Organização do código em funções.
- Uso de listas e do método `append`.
- Laços de repetição: uso do `for` para percorrer listas e do `while` para repetir um bloco até uma condição ser satisfeita.
- Tratamento de exceções com `try/except`, para evitar que o programa quebre quando o usuário digita um valor inválido.
- Uso de dicionários para criar chaves, atribuir e armazenar valores importantes nelas conforme for necessário.
- Operadores ternários para simplificar condições em uma linha.
- Docstrings para documentar o que cada função faz, com exemplos de entrada e saída.
- Fluxo básico de Git e GitHub (commits, push, README, pull request).
